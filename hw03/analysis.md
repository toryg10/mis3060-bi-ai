# HW03 – Executive Changes vs. Earnings Timing

Most executive changes in our data came before earnings: 20 of the 27 events were filed ahead of the company's next earnings release, 2 fell in the same week, and only 5 came after. The pattern was not the same for every company, though. JPMorgan and Walmart announced every change before earnings or in the same week, while Microsoft leaned the other way, with 2 of its 3 events coming after earnings. These counts should be read with some caution, because several rows come from a single 8-K filing; for example, one Walmart filing on January 16 produced five rows and one JPMorgan filing on June 25 produced four, so the 27 events really reflect only 16 separate filings. One likely reason companies announce leadership changes before earnings is to get the news out ahead of the earnings call, so executives are not answering questions about it for the first time in front of analysts.
